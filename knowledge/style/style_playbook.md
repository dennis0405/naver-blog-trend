## Current Observed Style

### 제목

- 특정 기술·사건·프로젝트를 다루는 초안이라면 핵심 대상을 먼저 밝히고, 분석 관점이나 경험 범위를 뒤에 덧붙인다. 관찰 수: 4/4건. confidence: high.
- 경험형 초안이라면 과정이나 관점의 변화를 제목에서 예고하되, 결과를 과장하거나 본문에 없는 성과를 추가하지 않는다. 관찰 수: 2/4건. confidence: medium.

### 도입

- 배경지식이 필요한 초안이라면 대상의 성격과 작성 맥락을 먼저 설명하고 본문 범위를 짧게 안내한다. 관찰 수: 4/4건. confidence: high.
- 법적 판단, 성능 평가처럼 오해 가능성이 큰 주제라면 분석 범위와 판단을 유보할 사항을 초반에 명시한다. 관찰 수: 2/4건. confidence: medium.

### 구조

- 논점이나 시간 단계가 여러 개라면 배경에서 세부 분석을 거쳐 실무적 정리로 이동한다. 관찰 수: 4/4건. confidence: high.
- 세부 쟁점이 셋 이상이라면 각 절이 질문이나 주장 하나만 담당하도록 구획한다. 관찰 수: 3/4건. confidence: medium.
- 회고형 초안이라면 시간 순서를 유지하면서 각 단계의 문제, 판단, 결과가 드러나게 편집한다. 관찰 수: 2/4건. confidence: medium.

### 문단 리듬

- 개념 설명이 길다면 사실·설명 문단과 해석·평가 문단을 번갈아 배치한다. 관찰 수: 4/4건. confidence: high.
- 사건이나 경험을 다룬다면 한 문단에 한 단계만 두어 시간적·논리적 진행을 분명히 한다. 관찰 수: 3/4건. confidence: medium.
- 짧은 문단을 사용하되 원인과 결과가 분리되어 의미가 끊기면 인접 문단으로 묶는다. 관찰 수: 3/4건. confidence: medium.

### 코드·목록·표

- 구현 재현보다 개념이나 경험 전달이 중심이라면 코드 블록을 억지로 추가하지 말고 필요한 기술 용어와 동작을 본문에서 설명한다. 관찰 수: 4/4건. confidence: high.
- 근거·장점·결과처럼 병렬 정보가 셋 이상일 때만 짧은 목록을 사용하고, 목록 전후에 그 의미를 해설한다. 관찰 수: 3/4건. confidence: medium.
- 동일한 비교 축과 충분한 수치가 없다면 표를 만들지 않는다. 관찰 수: 4/4건. confidence: medium.
- 코드·목록·표를 추가할 때는 원문에 없는 값, 실행 결과 또는 비교 기준을 추정해 채우지 않는다. 관찰 수: 4/4건. confidence: high.

### 어조·전환

- 전문 용어는 처음 등장할 때 정의하거나 구체적인 상황과 연결하고, 이후 표기를 통일한다. 관찰 수: 4/4건. confidence: high.
- 사실과 개인적 평가가 함께 있다면 문장이나 인접 문단 수준에서 경계를 분명히 한다. 관찰 수: 4/4건. confidence: high.
- 관점이 바뀔 때는 반론, 추가 근거, 시간 경과 또는 판단 변화 중 실제 관계를 전환 문장으로 밝힌다. 관찰 수: 3/4건. confidence: medium.

### 결말

- 분석형 초안이라면 근거를 그대로 반복하지 말고, 그 근거에서 도출되는 실무적 판단 기준으로 마무리한다. 관찰 수: 3/4건. confidence: medium.
- 회고형 초안이라면 경험 전후의 인식 변화와 다음 행동을 연결한다. 관찰 수: 2/4건. confidence: medium.
- 결말에서도 원문에 없는 전망이나 확정되지 않은 후속 계획을 단정적으로 추가하지 않는다. 관찰 수: 2/4건. confidence: medium.

### 편집 규칙

- 플랫폼 메뉴, 로그인, 반응, 댓글, 태그 등 본문 밖의 요소는 제거하되 작성자가 의도한 참고 목록은 보존한다. 관찰 수: 4/4건. confidence: high.
- 외부 자료가 언급되면 링크만 나열하지 말고 어떤 주장이나 맥락을 뒷받침하는지 설명한다. 관찰 수: 3/4건. confidence: medium.
- 기술 용어의 한글·영문 표기는 최초 등장 때 정리하고 이후 한 형태로 통일한다. 관찰 수: 4/4건. confidence: high.
- 수치, 조건, 인과관계, 불확실성 및 작성자의 사실·의견 구분을 보존하며, 누락된 정보를 추측해 보충하지 않는다. 관찰 수: 4/4건. confidence: high.

### confidence

- 플랫폼 공통 규칙은 같은 날 확보된 네이버 2건과 Velog 2건에서 함께 확인된 특징으로 제한했다. 비교 가능 표본: 4건. 종합 confidence: medium.
- 최근 7일의 고유 입력은 18건이지만 Velog는 2건뿐이며, 나머지 날짜에는 교차 비교 자료가 없었다. 공통 규칙을 전체 18건의 반복 패턴으로 확대 해석하지 않는다. confidence: high.
- 이전 공통 playbook의 규칙 가운데 최신 교차 관찰로 다시 확인된 제목의 핵심 대상 제시, 소제목 중심 구획, 한 문단 한 설명 단위, 용어 최초 설명, 목적에 따른 목록 사용만 유지했다. confidence: medium.
