# Velog Style Playbook

## Human Rules

- Markdown의 제목, 목록, 표, 코드 블록, 링크를 의미에 맞게 사용한다.
- 초안에 없는 사실, 수치, 날짜, 코드, URL은 추가하지 않는다.

## Current Observed Velog Style

### 제목

- 프로젝트 경험형 초안이라면 시작 단계와 도달 결과를 연결해 글의 진행 범위를 예고한다. 관찰 수: 1/2건. confidence: low.
- 기술·사회 쟁점 분석이라면 구체적 대상과 더 넓은 기술적 논점을 함께 제시한다. 관찰 수: 1/2건. confidence: low.

### 도입

- 민감하거나 오해 가능성이 있는 주제라면 참고 범위와 판단을 유보할 지점을 본론보다 먼저 밝힌다. 관찰 수: 1/2건. confidence: low.
- 성장 회고라면 참여 동기와 당시의 고민을 먼저 제시해 이후 성과와 관점 변화의 맥락을 만든다. 관찰 수: 1/2건. confidence: low.

### 구조

- 논점이나 경험 단계가 여러 개라면 짧은 문장형 소제목을 연속 배치하고 각 절이 하나의 질문이나 단계를 담당하게 한다. 관찰 수: 2/2건. confidence: high.
- 분석형 초안은 근거를 차례로 검토한 뒤 원칙적 판단으로 이동하고, 회고형 초안은 시간 순서와 주제별 성찰을 결합한다. 관찰 수: 2/2건. confidence: medium.
- Markdown 소제목 계층은 단계 수에 맞게 일관되게 유지하되, 관찰되지 않은 복잡한 중첩 구조를 임의로 추가하지 않는다. 관찰 수: 2/2건. confidence: medium.

### 문단 리듬

- 한두 가지 사실이나 판단만 담은 짧은 문단을 이어 읽는 속도를 유지한다. 관찰 수: 2/2건. confidence: high.
- 핵심 판단은 단독 문단으로 분리해 앞선 설명의 요약이나 다음 절의 전환점으로 사용한다. 관찰 수: 2/2건. confidence: high.

### 코드·목록·표

- 구현 코드보다 이슈 분석, 검토 과정, 엣지 케이스 또는 리뷰 결과가 중심이라면 코드를 억지로 추가하지 않고 산문으로 설명한다. 관찰 수: 1/2건. confidence: low.
- 관련 작업이나 참고 대상을 글 끝에 짧은 Markdown 목록으로 정리할 수 있다. 관찰 수: 1/2건. confidence: low.
- 코드 블록의 언어 지정, 표의 정렬, 인라인 링크 배치에 관한 반복 관찰이 없으므로 외부 관행을 Velog 규칙으로 단정하지 않는다. 관찰 수: 코드 0/2건, 표 0/2건. confidence: low.
- 코드나 표가 실제 초안에 있다면 내용과 비교 기준은 보존하되, 이번 표본만으로 고유한 배치 형식을 강제하지 않는다. 관찰 수: 0/2건. confidence: low.

### 어조·전환

- 개인 경험과 기술 판단을 함께 다룬다면 1인칭을 유지하되 사실과 의견의 경계를 분명히 한다. 관찰 수: 2/2건. confidence: high.
- 질문형 전환을 사용할 때는 바로 다음 문단에서 설명이나 근거로 답한다. 관찰 수: 1/2건. confidence: low.
- 회고의 감정 표현은 기술적 배움이나 판단 변화로 다시 연결할 때만 유지한다. 관찰 수: 1/2건. confidence: low.

### 결말

- 쟁점 분석 초안이라면 정답을 과도하게 단정하지 말고 독자가 확인할 실무 조건을 제시한다. 관찰 수: 1/2건. confidence: low.
- 성장 회고라면 도입의 고민을 회수하고 달라진 관점과 다음 과제를 연결한다. 관찰 수: 1/2건. confidence: low.
- 참고 목록을 덧붙일 때는 본문 결론과 분리하고 각 항목의 관련성이 드러나게 한다. 관찰 수: 1/2건. confidence: low.

### 편집 규칙

- Markdown 소제목이 촘촘하다면 각 절의 첫 문단이 소제목의 질문이나 주장을 바로 이어받도록 편집한다. 관찰 수: 2/2건. confidence: medium.
- 태그, 팔로우, 이전 글, 댓글 등 서비스 UI는 제거하되 작성자가 본문에 의도적으로 넣은 참고 링크와 목록은 보존한다. 관찰 수: 2/2건. confidence: high.
- 링크는 관련 주장 가까이에 배치하고, 링크만으로 의미를 대신하지 않도록 본문에 자료의 역할을 설명한다. 관찰 수: 1/2건. confidence: low.
- 이모지나 구어적 마무리는 회고의 개인성을 살리는 경우에만 제한적으로 사용한다. 관찰 수: 1/2건. confidence: low.
- 코드 블록, 표, 링크의 세부 Markdown 문법은 실제 초안에 해당 요소가 있을 때만 점검하며 관찰되지 않은 형식을 새로 강제하지 않는다. 관찰 수: 0/2건. confidence: low.

### confidence

- 최근 7일 Velog 고유 입력은 2건뿐이다. 짧은 문장형 소제목과 짧은 문단은 두 글에서 반복됐지만 전체 플랫폼 경향으로 일반화하기에는 표본이 적다. 종합 confidence: medium.
- 분석형과 회고형이 각각 1건이므로 제목, 도입, 결말 및 목록 사용은 모두 조건부 low-confidence 규칙이다.
- 코드 블록과 표는 관찰되지 않았다. 네이버 자료나 일반적인 Markdown 관행을 근거로 Velog 전용 규칙을 추정하지 않는다. confidence: high.
