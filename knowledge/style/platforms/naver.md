# Naver Style Playbook

## Human Rules

- 네이버 편집기에 바로 옮길 수 있는 읽기 흐름과 서식을 우선한다.
- 초안에 없는 사실, 수치, 날짜, 코드, URL은 추가하지 않는다.

## Current Observed Naver Style

### 제목

- 검색형 안내나 기술 해설 초안이라면 핵심 기술·대상을 앞에 두고 범위, 효용 또는 문서 유형을 뒤에 덧붙인다. 관찰 수: 11/16건. confidence: high.
- 프로젝트 회고라면 핵심 대상과 시행착오·변화의 관점을 함께 예고한다. 관찰 수: 5/16건. confidence: medium.
- 연재 표식, 회차, 시점 또는 긴 설명형 부제는 실제로 글의 위치나 범위를 구분할 때만 사용한다. 관찰 수: 3/16건. confidence: low.

### 도입

- 안내·해설형 초안이라면 독자의 문제나 기술의 필요성을 제시한 뒤 다룰 범위를 빠르게 밝힌다. 관찰 수: 9/16건. confidence: high.
- 회고형 초안이라면 시작 계기, 작성자의 역할 또는 초기 기대를 제시해 이후 문제 해결의 기준점을 만든다. 관찰 수: 5/16건. confidence: medium.
- 학습 메모처럼 범위가 좁다면 긴 인사나 문제 제기를 억지로 붙이지 말고 기록의 범위만 밝힌다. 관찰 수: 1/16건. confidence: low.

### 구조

- 다룰 항목이 셋 이상이라면 큰 주제를 소제목으로 나누고 각 절이 개념, 기능, 문제 또는 판단 하나를 담당하게 한다. 관찰 수: 13/16건. confidence: high.
- 절차·실습형 초안이라면 준비와 기반 설정에서 구현, 연동, 검증 결과로 이어지는 선행 순서를 유지한다. 관찰 수: 6/16건. confidence: medium.
- 회고·트러블슈팅 초안이라면 배경 또는 상황, 문제, 원인 탐색, 해결, 결과와 교훈 순으로 재배열한다. 관찰 수: 5/16건. confidence: medium.
- 비교형 초안이라면 각 대상에 동일한 평가 축을 적용하고 마지막에 선택 조건을 정리한다. 관찰 수: 3/16건. confidence: low.

### 문단 리듬

- 모바일 게시용 초안이라면 한 문단에 핵심 하나만 남기고 소제목과 문단 사이에 충분한 간격을 둔다. 관찰 수: 13/16건. confidence: high.
- 핵심 용어·단계·판단을 독립된 줄로 분리할 수 있지만, 문장을 임의의 글자 수로 잘라 파편화하지 않는다. 관찰 수: 7/16건. confidence: medium.
- 코드 중심 실습이라면 짧은 설명과 코드·결과 단위를 교대하고, 회고라면 짧은 감상 뒤에 기술적 원인이나 판단을 연결한다. 관찰 수: 4/16건. confidence: medium.

### 코드·목록·표

- 선택지, 단계, 장단점 또는 반복 필드가 셋 이상이면 목록이나 표로 바꾸되 모바일 화면에서 관계가 유지되는지 확인한다. 관찰 수: 10/16건. confidence: high.
- 순서 준수가 필요한 절차에는 번호 목록을, 순서가 중요하지 않은 특징·진단 기준에는 항목 목록을 사용한다. 관찰 수: 4/16건. confidence: medium.
- 실습형 초안이라면 코드 앞에 목적과 주의점을 쓰고, 뒤에는 핵심 동작, 결과 또는 다음 단계를 설명한다. 관찰 수: 4/16건. confidence: medium.
- 같은 기준으로 비교할 대상이나 수치가 충분할 때만 표를 사용하고, 표 다음에는 수치의 체감 의미나 선택 기준을 해설한다. 관찰 수: 3/16건. confidence: low.

### 어조·전환

- 안내·해설형 초안은 명확한 설명체를 기본으로 하고, 입문자를 대상으로 할 때만 대화형 존댓말이나 질문형 전환을 제한적으로 사용한다. 관찰 수: 9/16건. confidence: high.
- 회고·리뷰형 초안은 1인칭 경험과 감정을 허용하되 사실, 원인, 개인적 평가를 구분한다. 관찰 수: 6/16건. confidence: medium.
- 논점이 바뀔 때는 다음 단계, 시간 흐름, 비교 또는 요약을 알리는 짧은 전환 문장이나 소제목을 둔다. 관찰 수: 9/16건. confidence: high.
- 영문 기술 용어는 첫 등장 때 역할이나 한국어 의미를 설명하고 이후 표기를 통일한다. 관찰 수: 13/16건. confidence: high.

### 결말

- 긴 안내·해설형 초안이라면 핵심 판단 기준을 압축하고 독자의 다음 행동을 한 가지로 좁힌다. 관찰 수: 10/16건. confidence: high.
- 회고형 초안이라면 해결 결과와 재사용할 교훈을 정리하고 실제 후속 작업이 있을 때만 다음 단계를 예고한다. 관찰 수: 5/16건. confidence: medium.
- 리뷰·비교형 초안이라면 장점뿐 아니라 제약과 대안을 함께 검토한 뒤 적합한 사용 조건을 제시한다. 관찰 수: 2/16건. confidence: low.
- 신청·문의·후속 글 예고는 목적이나 계획이 명확할 때만 정보 본문과 분리해 배치한다. 관찰 수: 4/16건. confidence: medium.

### 편집 규칙

- 네이버 편집기에서 생긴 메뉴, 공감, 공유, 댓글, 저작권, 방문 통계, 관련 글 등의 인터페이스 문구를 본문에서 제거한다. 관찰 수: 16/16건. confidence: high.
- Markdown 문법에 의존하지 말고 네이버 편집기에서 실제로 보이는 소제목, 일반 문단, 번호 목록, 글머리표, 표 또는 인용 요소로 변환한다. 직접적인 서식 관찰 수: 7/16건. confidence: medium.
- 강제 줄바꿈과 특수 공백은 의미 단위의 문단 간격으로 정규화하고, 제목·표·본문에 반복된 같은 설명은 한 번만 남긴다. 관찰 수: 11/16건. confidence: high.
- 코드가 포함되면 언어, 들여쓰기, 코드 경계를 복원하고 파일명·계층명 표기를 통일한다. 관찰 수: 4/16건. confidence: medium.
- 해시태그는 본문과 분리해 끝에 배치하고 주제와 직접 관련된 것만 남긴다. 관찰 수: 4/16건. confidence: medium.
- 수집 분류와 다른 서비스의 흔적이 섞일 수 있으므로 관찰된 모든 서식을 네이버 고유 기능으로 단정하지 않는다. 관찰 수: 2/16건. confidence: medium.

### confidence

- 최근 7일 네이버 고유 입력은 16건이다. 소제목 분할, 짧은 문단, 핵심 대상이 드러나는 제목, 용어 표기 통일, 인터페이스 제거는 반복성이 높아 high confidence다.
- 코드 배치, 표, 회고 어조처럼 글의 유형에 좌우되는 특징은 medium 이하로 적용한다.
- 날짜별 표본의 목적이 안내, 실습, 비교, 리뷰, 연구 요약, 회고로 다양하므로 한 유형에서만 나타난 제목·도입·결말 장식은 일반 규칙으로 사용하지 않는다. 종합 confidence: high.
